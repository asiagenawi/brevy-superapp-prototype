# Brevy Super App — Clickable Prototype

Non-functional clickable prototype for the ACL Caregiver AI Prize Challenge (Phase 1, Track 1).

The home screen is composed, not static: modules are selected, ordered, and capped for each caregiver.
Switch personas to watch the same app reshape itself — including an SMS-only experience with no app at all.

**Live prototype:** https://asiagenawi.github.io/brevy-superapp-prototype/

Single self-contained HTML file (`index.html`) — no build step, no dependencies. Open it locally or serve it anywhere.
